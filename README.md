# 🧳 Travel Management System

A complete web-based Travel Management System built to streamline and digitize the tour booking process. This project allows users to browse tour packages, register/log in, book tickets, and view their booking history – all from a unified interface.

## 🌐 Features Overview

- 🏠 **Home Page**: Entry point with basic navigation and overview.
- 📝 **User Registration**: New users can register securely.
- 🔐 **User Login**: Returning users can log in to manage bookings.
- 🗺️ **Tour Destinations**: List of all available tour packages.
- 📋 **Tour Details**: View detailed info about each destination.
- 🎟️ **Ticket Booking**: Users can select a destination and book tickets.
- 📜 **Tour History**: Displays past bookings of the logged-in user.

---

## 🎯 Objective

To develop a user-friendly platform that simplifies the travel and tour management process by:

- Providing an interface for users to explore and book travel destinations
- Maintaining user profiles and travel history
- Automating tour bookings and data storage
